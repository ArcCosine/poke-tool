# poke-tool - 포켓몬 챔피언스 배틀 분석 및 파티 구성 시뮬레이터

[日本語](../README.md) | [English](README_en.md) | [한국어](README_ko.md) | [繁體中文](README_zh-Hant.md) | [简体中文](README_zh-Hans.md)

🌐 **웹 애플리케이션**: [https://poke-tool.pages.dev/](https://poke-tool.pages.dev/)

포켓몬 챔피언스 플레이어를 위한 배틀 데이터 분석, 노력치 계산 및 파티 구성 시뮬레이션 웹 애플리케이션입니다.  
클라이언트 사이드 완결형(로컬 퍼스트)으로 설계되어 서버 의존성 없이 빠르고 안전하게 개인정보를 보호하며 배틀 환경을 분석할 수 있습니다.

---

## 🌟 주요 기능

### 1. 노력치 계산 및 실수치 조정 (EV Calculator)
- **직관적인 스텝 단위 입력**: 0~32단계 스텝 UI(+1 / -1, 0 초기화, 32 최대화 버튼)를 통한 간편한 노력치 분배.
- **실수치 Lv.50 실시간 계산**: 종족값, 성격 보정, 노력치 투자에 따른 Lv.50 기준 실수치를 즉시 확인.
- **내구력 최적화 엔진**: 잔여 노력치를 물리 내구와 특수 내구의 밸런스($H = B + D$ 등 종합 내구 지수 극대화)에 맞춰 자동으로 최적 배분.
- **URL 공유**: 조정한 포켓몬의 스탯 구성을 Base64 형식의 URL로 생성하여 간편하게 북마크 및 공유 가능.

### 2. 화력(결정력) 및 내구력 순위 (Stat Ranking)
- **최대 결정력 지수 순위**: 특성(천하장사, 무아지경 등), 자속 보정(적응력 등), 기술 위력을 종합 반영한 실전 최대 결정력을 산출.
- **물리 및 특수 내구 지수 순위**: 방어형 특성(퍼코트, 얼음인분, 멀티스케일 등)을 고려한 실질 내구 지수 랭킹 제공.
- **상세 필터링 옵션**:
  - 포켓몬 타입 / 기술 타입 / 물리·특수 분류 필터
  - **메가진화 포켓몬 제외**: 메가진화 포켓몬을 순위에서 제외하는 필터 토글
  - **반동 기술(충전기) 제외**: 파괴광선, 기가임팩트, 하이드로캐논 등 사용 후 1턴간 행동 불능이 되는 충전 반동기를 제외한 실전형 화력 순위 제공
- **오름차순 / 내림차순 정렬**: 각 지수값 기준 자유로운 순위 정렬 지원.

### 3. 파티 구성 시뮬레이터 (Party Simulator)
- **6마리 파티 편성**: 포켓몬, 도구, 성격, 특성, 노력치, 기술(4개)을 자유롭게 구성.
- **방어 상성 일관성 분석**: 파티 전체의 약점, 반감, 무효 타입을 시각화하여 팀의 공통 약점을 신속하게 진단.
- **공격 견제폭 분석**: 파티의 공격 기술이 18개 전 타입의 약점을 얼마나 찌를 수 있는지 커버율을 점수화.
- **로컬 파티 저장 및 관리**: 브라우저의 IndexedDB 및 localStorage를 활용한 오프라인 저장(이름 수정, 복수 파티 관리 지원).
- **파티 URL 공유 기능**: 완성된 파티 구성을 Base64URL 링크로 공유. 공유받은 URL에서 즉시 파티를 복원하고 편집 및 저장이 가능.

### 4. 다양한 소셜 공유 시스템 (Share Dialog)
- **Web Share API 지원**: 모바일 기기 및 지원 브라우저에서 OS 네이티브 공유 시트(AirDrop, 메시지, 설치된 앱 등)를 직접 호출.
- **원클릭 SNS 공유**:
  - X (구 Twitter)
  - Bluesky
  - LINE
  - WhatsApp
  - Weibo (웨이보)
  - KakaoTalk (카카오톡)
- **원클릭 URL 복사**: 공유용 링크를 클립보드에 즉시 복사.

### 5. 다국어 지원 (i18n)
- **5개 언어 완전 지원**: 한국어 (`ko`), 일본어 (`ja`), 영어 (`en`), 번체 중국어 (`zh-Hant`), 간체 중국어 (`zh-Hans`).
- **다국어 인크리멘탈 검색**: 포켓몬 및 기술 검색 시 한글(초성/완성형), 가나, 로마자, 영어, 한자(번체/간체) 모두 지원.

### 6. UI 및 접근성
- **다크 모드 / 라이트 모드**: 고대비 가독성을 확보하여 어두운 환경에서도 눈이 편안한 테마 디자인.
- **반응형 레이아웃**: 스마트폰, 태블릿, PC 화면에 모두 최적화된 UnoCSS 기반의 모던 UI.

## 🚀 개발 및 환경 설정

### 사전 요구 사항
- Node.js (v18 이상 권장)
- npm

### 1. 저장소 클론 및 패키지 설치
```bash
git clone https://github.com/ArcCosine/poke-tool.git
cd poke-tool
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```
로컬 서버가 실행됩니다 (기본 주소: `http://localhost:5173`).

### 3. 테스트 실행
Vitest 테스트 스위트를 실행합니다:
```bash
npm test
```

### 4. 프로덕션 빌드
OGP 생성, TypeScript 타입 검사 및 번들링을 진행합니다:
```bash
npm run build
```
빌드 산출물은 `dist/` 폴더에 생성됩니다.

### 5. 배포 (Cloudflare Pages)
```bash
npm run deploy
```
