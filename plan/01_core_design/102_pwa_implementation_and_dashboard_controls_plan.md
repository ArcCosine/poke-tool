# 計画書: PWA化およびダッシュボードへのオフライン制御・インストール促進機能の追加

## 1. 概要
本プロジェクトを PWA (Progressive Web App) 化し、ネットワーク接続のない環境（オフライン）でも全機能（計算、パーティ編成、画像表示、技選択）を完全に利用可能にする。
ユーザーの要望に基づき、以下の機能とUIを実装する：
1. **ダッシュボードへの「オフライン用に全データ保存」機能の実装**（案2: ユーザーの意思による一括キャッシュとプログレス表示）
2. **ダッシュボードへの「ホーム画面に追加（インストール）」UIの実装**（Android/PCのプロンプト起動 ＆ iOS向けの案内モーダル対応）
3. **PWAの主要機能（マニフェスト、アプリアイコン、Workbox Service Worker、App Shortcuts、更新トースト）の導入**

---

## 2. 提案するPWA機能一覧

| 機能 | 概要・メリット |
| :--- | :--- |
| **① App Shortcuts (アプリショートカット)** | スマホのホーム画面アイコン長押しで「パーティ編成」「ランキング」「努力値計算」へ1タップで直接起動。 |
| **② 自動更新通知トースト (Update Toast)** | 新レギュレーションやデータ更新時、画面下に「新しいバージョンが利用可能です [更新]」を表示し、ワンタップで最新版へリロード（キャッシュ滞留防止）。 |
| **③ ネットワーク状態インジケーター** | ヘッダーまたはダッシュボードに「🟢 オンライン / 🟡 オフライン動作中」を控えめに表示し、オフラインでも安心して使えることを視覚的に伝達。 |
| **④ スタンドアローンモード (Standalone)** | ブラウザのアドレスバーや戻るボタンを非表示にし、ネイティブアプリ同等の全画面UIを提供。 |
| **⑤ オフラインストレージ管理** | キャッシュした容量（約45MB）の表示と、不要になった際のキャッシュ削除（ストレージ解放）機能。 |

## 3. 各機能の詳細設計

### (1) ホーム画面に追加ボタン (PWA Install Prompt)
- **配置場所**: ダッシュボードの Hero セクション直下（または専用のプレミアムバナーカード）
- **挙動ロジック**:
  - `beforeinstallprompt` イベントをリッスンし、インストール可能な環境（Android Chrome、PC Chrome/Edge等）では「ホーム画面に追加」ボタンを押すことでブラウザ標準のインストールプロンプトを直接起動。
  - iOS Safari（`beforeinstallprompt` 非対応）の場合は、クリック時に「Safariの共有ボタン ⎋ をタップし、『ホーム画面に追加』を選択してください」という図解ステップ付きの案内ダイアログ（共通コンポーネント `Dialog` を使用）を表示。
  - すでにインストール済み（スタンドアローンモード: `display-mode: standalone`）の場合は、重複を避けるため「✅ インストール済み」バッジとして表示。

### (2) オフライン用に全データ保存ボタン (Offline Data Management)
- **配置場所**: ダッシュボードのツールカード下部に「オフラインデータ管理」カードを配置
- **キャッシュ対象**:
  - ポケモンスプライト画像全341匹（`/assets/pokemon-sprites/*.png`）
  - タイプアイコン（`/assets/type-icons/*.png`）
  - 技分類アイコン（`/assets/categories/*.jpg`）
  - マスターデータ（`/data/pokemon_master.json`, `/data/moves_master.json`, `/data/items_master.json`, `/data/version.json`）
- **プログレス・フィードバック**:
  - ダウンロード中: プログレスバーとともに「データを保存中... (125 / 341 匹 - 36%)」をリアルタイム表示。
  - 完了時: 「✅ オフライン利用可能（全341匹・約45MB）」を表示。
  - キャッシュ削除ボタン: 「キャッシュをクリア」をクリックすることで端末のストレージを即時解放可能。

### (3) `db.ts` のオフライン耐性強化
- 完全オフライン時に `fetch('/data/version.json')` が失敗しても、IndexedDB に保存されているマスターデータをそのまま利用して即座に起動できるようフォールバック処理を実装。

### (4) Web App Manifest と アプリアイコン
- 192x192 および 512x512 の高解像度 PNG アイコン（通常および maskable）を生成・配置。
- `manifest.webmanifest`:
  - `name`: "poke-tool - ポケモンチャンピオンズ対戦分析"
  - `short_name`: "poke-tool"
  - `display`: "standalone"
  - `theme_color`: "#4f46e5"
  - `background_color`: "#0f172a"
  - `shortcuts`: パーティ編成、ランキング、努力値計算へのダイレクトリンク
