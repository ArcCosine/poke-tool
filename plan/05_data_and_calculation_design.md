# 05_data_and_calculation_design.md - ポケモンデータ構造と火力・耐久計算ロジックの設計

本ドキュメントでは、検索機能およびシミュレーターの基礎となるポケモンデータのデータ構造（JSON）と、最大火力・最大耐久を算出するための計算ロジックについて計画します。

---

## 1. PokeAPI を活用したビルド時クローラーとデータ生成設計

PokeAPI（無料のポケモン情報API）から直接本番環境へリクエストを投げるとサーバー負荷や遅延の原因となるため、開発時（またはビルド前）に以下の手順でデータを自動抽出し、極限まで軽量化したマスタファイルを生成します。

```text
[PokeAPI] --(開発時スクリプト: scripts/fetch_pokeapi.ts)--> [必要なキーのみ抽出]
                                                                  |
[IndexedDB (ブラウザ側キャッシュ)] <-- (ロード) -- [Brotli/Gzip圧縮JSON (約100KB)]
```

### 1.1 クローラーの仕様
- **実装場所**: `scripts/fetch_pokeapi.ts` (TypeScript / Node.js等で実行)
- **処理**:
  1. PokeAPI の `/pokemon` および `/move` エンドポイントを巡回。
  2. ポケモンのID、日本語名、タイプ、種族値、覚える技、特性のみを取得。
  3. 技のID、日本語名、タイプ、分類（物理/特殊/変化）、威力、命中率を取得。
  4. 日本語訳は `/pokemon-species` や `/move` から日本語ロケール (`ja`) のデータを紐づけ。
  5. 最適化した JSON を `src/data/pokemon_master.json` および `src/data/moves_master.json` として出力。

## 2. ポケモンデータ構造 (JSON)

静的に保持するポケモンのマスターデータのスキーマです。ファイルサイズを最小化するため、キー名を短縮化するなどの工夫も取り入れます。

### 2.1 ポケモン基本データ (`pokemon_master.json`)
```json
[
  {
    "id": 1,
    "name": "フシギバナ",
    "types": ["grass", "poison"],
    "base_stats": {
      "hp": 80,
      "attack": 82,
      "defense": 83,
      "sp_attack": 100,
      "sp_defense": 100,
      "speed": 80
    },
    "abilities": ["しんりょく", "ようりょくそ"],
    "learnable_moves": [1, 2, 5, 10] // 技IDのリスト
  }
]
```

### 1.2 技データ (`moves_master.json`)
```json
[
  {
    "id": 1,
    "name": "ハードプラント",
    "type": "grass",
    "category": "special", // physical, special, status
    "power": 150,
    "accuracy": 90,
    "pp": 5
  }
]
```

## 2. 火力・耐久の計算ロジック

実数値の計算式はポケットモンスター本編の仕様に準拠します（レベル50固定を想定）。

### 2.1 ステータス実数値の計算式
- **HP**: 
  $$\text{HP} = \lfloor (\text{種族値} \times 2 + \text{個体値} + \lfloor \text{努力値} / 4 \rfloor) \times \frac{\text{レベル}}{100} \rfloor + \text{レベル} + 10$$
  - レベル50、個体値31（最速・最大想定）の場合：
    $$\text{HP} = \text{種族値} + 60 + \lfloor \text{努力値} / 4 \rfloor + 15 = \text{種族値} + 75 + \lfloor \text{努力値} / 4 \rfloor$$
- **攻撃/防御/特攻/特防/素早さ**:
  $$\text{実数値} = \lfloor (\lfloor (\text{種族値} \times 2 + \text{個体値} + \lfloor \text{努力値} / 4 \rfloor) \times \frac{\text{レベル}}{100} \rfloor + 5) \times \text{性格補正} \rfloor$$
  - レベル50、個体値31の場合：
    $$\text{実数値} = \lfloor (\text{種族値} + 20 + \lfloor \text{努力値} / 4 \rfloor) \times \text{性格補正} \rfloor$$
  - 性格補正は $1.1$, $1.0$, $0.9$ のいずれか。

### 2.2 最大火力（ダメージ指数）の計算
ランキング表示用の「最大火力」は、特定の相手を想定しない「火力指数（Damage Index）」を用いて計算します。

$$\text{火力指数} = \text{攻撃（または特攻）実数値} \times \text{技の威力} \times \text{タイプ一致補正(1.5)} \times \text{特性補正} \times \text{持ち物補正}$$

- **計算条件**:
  - レベル50、個体値31、努力値252振り、性格補正1.1（上昇）を適用した最大実数値をベースとする。
  - 特性（例: 「ちからもち」で攻撃2倍、「ようりょくそ」による素早さ変化等は火力に直接影響しないが、「こだわりハチマキ/メガネ」などの補正は考慮するかを設定可能にする）。
  - タイプ一致の場合、1.5倍の補正を適用。

### 2.3 最大耐久（耐久指数）の計算
耐久力は、受ける技の分類（物理・特殊）に応じて個別に計算します。

- **物理耐久指数**: 
  $$\text{物理耐久指数} = \text{HP実数値} \times \text{防御実数値}$$
- **特殊耐久指数**: 
  $$\text{特殊耐久指数} = \text{HP実数値} \times \text{特防実数値}$$
- **総合耐久指数**: 
  $$\text{総合耐久指数} = \text{物理耐久指数} + \text{特殊耐久指数}$$（または調和平均など）

- **計算条件**:
  - レベル50、個体値31、努力値は「HP極振り(252)」かつ「防御極振り(252)」または「特防極振り(252)」とし、性格補正1.1を適用した最大値をベースとする。

## 3. ランキングとフィルタリング設計

### 表示項目 (Top 30)
- 順位
- ポケモン名 (アイコン付き)
- 該当する技名 (火力検索の場合)
- 火力指数 / 耐久指数
- タイプ

### フィルタリング機能
- **タイプフィルタ**: 単一タイプまたは複合タイプを指定して絞り込み（例: 「ほのお」タイプのみ）。
- **技分類フィルタ**: 物理 / 特殊 の切り替え。
- **世代/地方制限** (必要に応じて拡張)。
