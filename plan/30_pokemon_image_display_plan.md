# 計画書：PokeAPIを使用したポケモン画像のランキング表示実装

本計画は、ランキング画面に PokeAPI でホスティングされているゲーム内ドット絵（Sprites）を表示し、ツールとしての視認性とビジュアルのクオリティを向上させるためのものです。

## 1. 背景と目的
現在、ランキング画面のポケモン名セルには画像が表示されていません。
ユーザー調査に基づき、著作権表示・免責事項を徹底した上で、最も非営利ファン開発ツールでデファクトスタンダードとなっている「PokeAPI」のホスティング画像を参照し、ドット絵の画像を表示します。

## 2. 仕様定義

### 2.1. 画像ソースの選定
- **画像URL**:
  `https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/${pokemonId}.png`
- **選定理由**:
  - `pokemon_master.json` 内の ID 体系（メガフシギバナのID: `10033` など）が PokeAPI のスプライトID体系と一致しているため、追加のマッピングテーブルなしで直接画像URLを動的に生成できます。
  - ゲーム内ドット絵（透過PNG、96x96ピクセル）はサイズが小さく、テーブルの行高さを圧迫せずに綺麗に収まります。

### 2.2. レイアウトのレスポンシブ設計
ポケモン名セル（`td`）の左側に画像（横幅約40px）を配置し、その右側に情報を並べます。

#### PC表示（タブレット以上）
```
[画像 (40x40)]  ポケモン名
               タイプバッジ
```

#### モバイル表示（スマホサイズ）
```
[画像 (40x40)]  ポケモン名
               タイプバッジ
               特性名
```
画像と右側のテキスト群が `flex items-center`（モバイルでは `items-start`）で横に並び、PCでは2行、モバイルでは3行で整然と配置されます。

### 2.3. 画像読み込みエラーへの対策
ネットワーク切断やデータが存在しない場合の対策として、`onError` イベントハンドラを利用して代替プレースホルダー（または画像を非表示にし、名前だけを表示）を適用するロジックを実装します。

### 2.4. 著作権免責事項の明記
ランキング表示カード（`Rankings List`）の下部に、データの著作権が任天堂等に帰属する非公式ファンサイトである旨を、多言語対応で明記します。

---

## 3. 実装アプローチ

### 3.1. `src/components/StatSearch/StatSearch.tsx` の修正
1. ポケモンの名前列（`Pokémon Name` セル）の HTML 構造を、`<img>` タグとテキストコンテンツが `flex` で横並びになる構造に拡張します。
2. 画像の `src` に PokeAPI の画像URLをセットし、`onError` で画像の非表示、あるいはフォールバック用マークへの切り替えを実装します。
3. `Rankings List` の `div` コンテナの下に、著作権表記を行うフッターを追加します。

### 3.2. テストの確認
- 画像表示処理の追加によって、既存のユニットテストや React のレンダリングに問題がないことを確認します。
- `npm run build` を実行して、ビルドエラーが発生しないことを確認します。
