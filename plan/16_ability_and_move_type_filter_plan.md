# 16_最大火力ランキングにおけるわざタイプフィルタリングと特性補正の実装計画

本計画は、最大火力ランキングにおける「わざタイプ」でのフィルタリング機能の追加、および「テクニシャン」「ちからもち」といった火力に直結する特性を加味した火力計算ロジックの実装手順を定義します。

---

## 1. 実装要件

### (1) 特性を加味した火力計算
火力ランキングの「最大火力」は、現在ポケモンの攻撃/特攻の最大ステータスと技の威力、およびタイプ一致（STAB）のみで計算されています。これに加えて、以下の火力補正特性を考慮した計算を行います。
ポケモンの持つ特性（`abilities`）のいずれかを適用したときに、最も高くなる火力をそのポケモンの「最大火力」として採用します。

#### 対象とする主要な火力補正特性と補正値
| 特性名（日） | 特性名（英） | 補正の分類 | 補正倍率と適用条件 |
| :--- | :--- | :--- | :--- |
| **ちからもち** / **よがみ** | Huge Power / Pure Power | ステータス補正 | 物理技使用時、物理攻撃ステータスを **2.0倍** にする。 |
| **ごりむちゅう** | Gorilla Tactics | ステータス補正 | 物理技使用時、物理攻撃ステータスを **1.5倍** にする。 |
| **テクニシャン** | Technician | 技威力補正 | 技の威力が **60以下** の場合、威力を **1.5倍** にする。 |
| **すなのちから** | Sand Force | 技威力補正 | 砂嵐環境下を想定し、「いわ」「じめん」「はがね」タイプの技の威力を **1.3倍** にする。 |
| **てきおうりょく** | Adaptability | STAB補正 | タイプ一致（STAB）による補正倍率を通常 1.5倍 のところ **2.0倍** にする。 |
| **トランジスタ** | Transistor | 技威力補正 | でんきタイプの技の威力を **1.3倍** にする（第9世代準拠）。 |
| **りゅうのあぎと** | Dragon's Maw | 技威力補正 | ドラゴンタイプの技の威力を **1.5倍** にする。 |

> [!NOTE]
> * ポケモンは複数の特性（`abilities`）を持ち得るため、それらの中で**最大火力を最も高くする特性**を自動的に選択して計算します。
> * メガハッサム（特性「テクニシャン」、しんか前含む）などのメガシンカ形態も `pokemon_master.json` に含まれているため、このロジックで自動的に計算に反映されます。

### (2) 「わざのタイプ」によるフィルタリング機能の追加
現在、UIには「ポケモンのタイプ（Type）」で絞り込むフィルターがありますが、ユーザーが「特定のタイプの技で最大火力を出せるポケモン」を探しやすくするために、「わざのタイプ」でのフィルタリングを追加します。

* **UI表示**: 検索対象が「最大火力（damage）」のときのみ「わざタイプ」セレクトボックスを有効または表示する。
* **フィルタ処理**: ポケモンの最大火力技のタイプが、指定された「わざタイプ」と一致するもののみを表示する。

## 2. 設計詳細

### (1) 火力計算ロジックの修正 (`src/utils/calculator.ts`)
`calculateMaxDamage` 内で、以下の流れで特性を加味した計算を行います。

1. **ベースステータス計算**: 攻撃力（物理/特殊）を計算する。
2. **特性ループ**: ポケモンの `abilities` リスト（空の場合はデフォルトの補正なし特性として扱う）に対してループを回す。
3. **技ループ**: ポケモンが習得可能な技についてループ。
4. **補正適用**:
   * **ステータス補正**: 特性が「ちからもち」「よがみ」（物理のみ2.0倍）、「ごりむちゅう」（物理のみ1.5倍）の場合、攻撃力を倍算する。
   * **技威力補正**:
     * 基本威力に対して、特性が「テクニシャン」かつ威力が60以下なら 1.5倍 にする。
     * 特性が「すなのちから」かつ技タイプが「いわ」「じめん」「はがね」なら 1.3倍 にする。
     * 特性が「トランジスタ」かつ技タイプが「でんき」なら 1.3倍 にする。
     * 特性が「りゅうのあぎと」かつ技タイプが「ドラゴン」なら 1.5倍 にする。
   * **STAB補正**:
     * 技タイプがポケモンのタイプに含まれる場合（STAB）、特性が「てきおうりょく」なら 2.0倍、それ以外なら 1.5倍 を乗算する。
5. **最大値の決定**: 各特性・各技の組み合わせの中で、最も高いダメージ指標 `Math.floor(OffenseStat * Power * STAB)` を求め、その値・技・適用した特性を返す。

### (2) UIの修正 (`src/components/StatSearch/StatSearch.tsx`)
1. フィルターに `selectedMoveType` 状態を追加する。
2. フィルター用セレクトボックスを追加し、`searchTarget === 'damage'` の時のみ表示する。
   * ラベルは「わざタイプ」とする。
3. ランキング一覧のフィルタリング処理に、`selectedMoveType` の条件を追加する。
   * `selectedMoveType !== 'all'` かつ `searchTarget === 'damage'` のとき、最大火力技のタイプが `selectedMoveType` と一致するもののみ通す。
4. 多言語化対応（`src/context/AppContext.tsx` の翻訳辞書に `moveType` などを追加）。
