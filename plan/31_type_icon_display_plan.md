# 計画書：タイプアイコン付きバッジの導入計画（ローカルアセット版）

本計画は、ランキング画面に表示される「ポケモンのタイプ」および「使用技のタイプ」について、ゲーム最新作に準拠した白抜きの記号アイコンを埋め込んだプレミアムなバッジデザインにアップデートするためのものです。
外部ネットワークに依存せず、Vite の静的アセットとして完全にローカルで動作する設計にします。

## 1. 背景と目的
現在、タイプバッジはテキスト（例:「ほのお」「ゴースト」）と背景色のみで構成されています。
対戦ツールとしての直感的な認識性を向上させるため、既存 of タイプバッジデザインの左側にミニアイコンを配置し、GAMEWITHなどの大手メディアと同等以上のビジュアルクオリティを実現します。
また、外部へのネットワークリクエストを排除し、「ローカルファースト」のポリシーを徹底します。

## 2. 仕様定義

### 2.1. アイコンアセットとパス
- **アセット取得元**: `partywhale/pokemon-type-icons` (MITライセンス) の全18タイプのSVGファイルを、プロジェクトローカルの `public/assets/type-icons/` ディレクトリに配備しました。
- **画像URL/パス**:
  `/assets/type-icons/${typeKey}.svg`
  ※`${typeKey}` は小文字 of 英語名（`fire`, `water`, `ghost` など）であり、当アプリが定義するタイプキーと一致します。
  ※これにより、本番ビルド時やオフライン環境でも確実に動作します。

### 2.2. バッジデザインのアップデート
バッジコンポーネントを以下のように再設計します。
```html
<span className="inline-flex items-center gap-1 px-1.5 py-0.5 sm:px-2 sm:py-0.5 text-[8px] sm:text-xs rounded-md font-medium tracking-wide text-white bg-...">
  <img
    src={`/assets/type-icons/${typeKey}.svg`}
    onError={(e) => {
      (e.target as HTMLImageElement).style.display = 'none';
    }}
    alt=""
    className="w-3 h-3 sm:w-3.5 sm:h-3.5 object-contain shrink-0 select-none"
    loading="lazy"
  />
  {/* タイプ名のテキスト */}
</span>
```
- **レイアウト**: `inline-flex` と `items-center` でアイコンと文字の縦中央を揃え、`gap-1` で適切な間隔を空けます。
- **エラーハンドリング**: `onError` 時は `style.display = 'none'` に切り替えることで、アイコンスペースを完全に詰め、従来のテキストのみのバッジ表示にフォールバックします。

### 2.3. 適用箇所
1. **ポケモン名前セルのタイプバッジ** (ライン2)
2. **使用技セルのタイプバッジ** (ライン2)
※同一の設計を適用し、一貫性を保ちます。
