# 計画書 127: ボトムナビゲーションのフォントサイズ調整によるスマホ幅2行表示の解消

## 1. 概要と背景
- **ユーザー要望**:
  - 画面最下部に固定表示されているボトムナビゲーション（下部メニュー）のテキストが、スマートフォンの横幅において2行に表示される現象を解消したい。
  - 改行禁止（`whitespace-nowrap`）は予期せぬ表示崩れのリスクがあるため使用せず、**フォントサイズを変更するだけの対応**とする。
  - PC画面やタブレット画面では現在の表示で問題ないため、レスポンシブにフォントサイズを調整する。

---

## 2. 原因と対策仕様

### 2.1 原因
- 対象ファイル: `src/components/common/Layout.tsx`
- 現在のラベル表示要素:
  ```tsx
  <span className="text-[10px] tracking-tight">
    {t(item.labelKey)}
  </span>
  ```
- スマートフォン画面幅（360px〜375px等）では6つの項目が並ぶため、1項目あたりの表示幅は約60px〜62.5px。
- 「ダッシュボード」（7文字）等のテキストが `10px`（約70px幅）では収まりきらず、自動改行されて2行になってしまう。

### 2.2 変更仕様
- 改行禁止クラスや不要なスタイルは追加せず、フォントサイズのみをレスポンシブに変更する：
  ```tsx
  <span className="text-[8.5px] sm:text-[10px] tracking-tight">
    {t(item.labelKey)}
  </span>
  ```
- **スマホ幅（通常）**: `text-[8.5px]`
  - 全角7文字（ダッシュボード）でも約59.5pxとなり、360px〜375pxの画面幅でも自然に1行で収まる。
- **タブレット・PC幅（`sm:` 以上）**: `sm:text-[10px]`
  - 従来の文字サイズ（10px）をそのまま維持。
