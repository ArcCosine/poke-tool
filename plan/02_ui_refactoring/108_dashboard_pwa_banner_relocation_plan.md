# 108_dashboard_pwa_banner_relocation_plan.md

## 目的
ダッシュボード画面（`src/pages/dashboard/main.tsx`）において、現在ヒーローヘッダー直下に配置されている「ホーム画面に追加」（PWAインストールバナー）を、「オフラインデータ管理」セクションの下（最下部）へ移動し、主要ツールカードへのアクセス性を向上させる。

## 現状と課題
- **現状の並び順**:
  1. ヒーローヘッダー (Pokémon Champions Ready バッジ, タイトル, 説明文)
  2. **ホーム画面に追加バナー（PWA Install Banner）**
  3. ツール一覧カード（火力・耐久ランキング、努力値計算、パーティ編成、パーティランキング）
  4. オフラインデータ管理カード（画像・マスターデータダウンロード、キャッシュ削除）
- **課題**:
  - ホーム画面に追加バナーがファーストビュー直下の目立つ位置を占有しており、ツールへの導線（各機能カード）が押し下げられている。
  - ユーザーが日常的に利用する主要機能カードおよびデータ管理の後にPWA追加バナーを配置する方が、画面全体の情報階層として自然である。

## 改修方針

### 1. レイアウト構成の変更
ダッシュボードの表示順序を以下のように並び替える：
1. **ヒーローヘッダー** (Hero Section)
2. **主要機能カードグリッド** (Feature Cards Grid)
3. **オフラインデータ管理カード** (Offline Storage Management Card)
4. **ホーム画面に追加バナー** (PWA Install Banner)

### 2. TDD (テスト駆動開発)
- `src/pages/dashboard/Dashboard.test.tsx` にて、DOM上の要素出現順序（「オフラインデータ管理」の後に「ホーム画面に追加」バナーが出現すること）を検証するテストを追加（Red）。
- `src/pages/dashboard/main.tsx` のJSX配置を変更（Green）。
- 既存の全テストがパスすることを確認。

## 開発ロードマップ
1. **計画書の作成・合意** (本ドキュメント)
2. **Red**: `Dashboard.test.tsx` に配置順序のテストを追加・検証
3. **Green**: `src/pages/dashboard/main.tsx` のセクション配置を移動
4. **Refactor & 全体検証**: 全体テスト（`npm test`）のパス確認
