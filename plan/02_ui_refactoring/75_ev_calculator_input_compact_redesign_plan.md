# 計画書: 努力値計算ツールの入力部分における間延び感解消とレイアウト引き締め (75_ev_calculator_input_compact_redesign_plan.md)

本計画は、努力値計算ツール (`EvCalculator.tsx` および `EvStatInput.tsx`) において、「努力値入力部分が間延びした印象になっている」という課題を解消し、**整然としたテーブル型レイアウト、明確な列ヘッダー、一体感のあるボタングループ設計により、密度感と視認性に優れた引き締まったUIへと刷新する**計画です。

---

## 1. 背景と課題分析

### ユーザー指摘
> 「努力値計算ツールの努力値入力部分が間延びした印象になっています。こちらを修正してください。」

### 課題の分析
1. **性格補正（▲/▼）の孤立と無駄なカラム消費**:
   - 現在のグリッドレイアウト（`md:grid-cols-12`）では、性格補正記号のためだけに `col-span-1` を割り当てており、記号がポツンと浮いて横方向に間延びした印象を与えています。
2. **努力値入力エリアの右側に生じる無駄な余白**:
   - `EvStatInput`（ボタン＋数値入力）に `col-span-7` が割り当てられていますが、コンポーネント自体の幅（約210px）に対してエリアが広すぎ、右側に大きな空きスペースが生じています。
3. **列ヘッダーの不在による視覚的骨格の欠如**:
   - 各ステータス行の上に「何がどこに並んでいるか」を示す列見出しが存在しないため、要素同士のまとまりが希薄で、縦横にスカスカした散漫な印象を与えています。
4. **`EvStatInput` の一体感の不足**:
   - ボタン（0, -1, +1, 32）と数値入力欄の間の隙間や配置が分離して見え、ひとつの操作ユニットとしての密度感が弱くなっています。

---

## 2. 改善方針と新レイアウト設計

### 2.1. 列ヘッダー付きの整然としたテーブル型レイアウトの導入
行の最上部に視覚的ガイドとなるヘッダー行を追加し、各要素を縦横に整列させます：

```text
┌────────────────────────────────────────────────────────┐
│ 努力値と実数値                             合計: 66/66 │
├────────────────────────────────────────────────────────┤
│ ステータス     種族値   努力値調整 (ステップ)   実数値 │
├────────────────────────────────────────────────────────┤
│ HP              91     [0][-1][ 32 ][+1][32]      198  │
│ 攻撃 ▲         134     [0][-1][  0 ][+1][32]      154  │
│ 防御            95     [0][-1][  0 ][+1][32]      115  │
│ 特攻           100     [0][-1][ 32 ][+1][32]      152  │
│ 特防           100     [0][-1][  2 ][+1][32]      122  │
│ 素早さ ▼        80     [0][-1][  0 ][+1][32]       81  │
└────────────────────────────────────────────────────────┘
```

### 2.2. カラム構成の最適化
各行を美しくバランスのとれたグリッドに再編します：
- **ステータス・性格補正列** (`col-span-3 sm:col-span-3`):
  - ステータス名（HP, 攻撃, 防御など）のすぐ横に性格補正記号（▲/▼）をインラインで配置。
  - 下部に種族値（`種族値: 134` / `Base: 134`）を表示。
- **努力値入力ユニット列** (`col-span-6 sm:col-span-6`):
  - `EvStatInput` のボタン群と数値入力を余白なく中央〜左寄りにジャストフィットで配置。
  - ボタングループとしてのまとまりを強化（`gap-1`〜`gap-1.5`）。
- **実数値出力列** (`col-span-3 sm:col-span-3` text-right):
  - 実数値（例: `198`）を大きく表示し、性格補正色を適用。

### 2.3. `EvStatInput.tsx` のボタングループ一体感強化
- ボタン群と入力欄の高さ・角丸・隙間を統一。
- 一体感のあるコントロールバーとしてデザインし、横に間延びせず引き締まった印象を演出。
- ボタン文字サイズ・押しやすさは維持しつつ、余計な余白を削減。

### 2.4. 各行のホバー効果とアクセシビリティ
- 各行に `hover:bg-slate-50/60 dark:hover:bg-slate-800/40 rounded-xl p-2.5 transition` を付与し、操作中の行を明確化。
- ダークモード時のコントラスト比を完全に維持。
