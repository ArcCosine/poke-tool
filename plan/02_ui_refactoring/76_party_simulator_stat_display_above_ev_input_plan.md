# 計画書: パーティ編成画面の努力値入力上部における実数値表示追加 (76_party_simulator_stat_display_above_ev_input_plan.md)

本計画は、パーティ編成画面（`PartySimulator.tsx`）の努力値入力セクションにおいて、**各ステータスの入力欄の直上（または入力セクション上部）にレベル50時の実数値をリアルタイム計算して表示する機能を追加する**計画です。

---

## 1. 背景と要件

### ユーザー要望
> 「パーティ編成画面の努力値入力の上の部分に、実数値を表示するようにしてください。」

### 主要要件と制約
1. **実数値のリアルタイム計算・表示**:
   - レベル50、個体値31、性格補正、設定された努力値（ステップ値）に基づく正確な実数値を算出（`getCalculatedStat` 関数を利用）。
   - 各ステータス（H, A, B, C, D, S）の数値入力欄の真上に対応する実数値を表示。
2. **換算表示の排除 (`AGENTS.md` ルール)**:
   - 0〜252などの従来の努力値への換算表示は一切出さない。
   - 入力・操作および表示はステップ値（0〜32）と実数値のみとする。
3. **性格補正の反映**:
   - 性格による上昇補正（赤色）および下降補正（青色）を実数値の文字色にも適用し、直感的な視認性を確保。
4. **UIアクセシビリティとコントラスト**:
   - 実数値の文字色は `text-slate-800 dark:text-slate-100` を基準とし、性格補正時は `text-red-500 dark:text-red-400` / `text-blue-500 dark:text-blue-400` で高コントラストを維持。
   - レスポンシブ対応（デスクトップ 6列、モバイル 3列×2行）。

## 2. UI・コンポーネント設計

### 2.1. レイアウト構成
各ポケモンスロットの努力値入力コンテナ内において、各ステータスカラムを「ラベル」→「実数値」→「数値入力欄」の3段構成とします：

```text
┌────────────────────────────────────────────────────────┐
│ 努力値 (ステップ) [実数値 Lv.50]           合計: 32/66 │
│                                                        │
│ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐        │
│ │H(HP)│ │A(攻)│ │B(防)│ │C(特)│ │D(特)│ │S(速)│ ←ラベル
│ │ 198 │ │ 154 │ │ 115 │ │ 152 │ │ 122 │ │  81 │ ←実数値(新設)
│ │[ 32]│ │[  0]│ │[  0]│ │[ 32]│ │[  2]│ │[  0]│ ←入力欄
│ └─────┘ └─────┘ └─────┘ └─────┘ └─────┘ └─────┘        │
└────────────────────────────────────────────────────────┘
```

### 2.2. 各要素のスタイル
- **セクションヘッダー**:
  - ラベル: `努力値 (ステップ)`
  - バッジ: `実数値 Lv.50`（`text-[10px] font-medium text-slate-500 dark:text-slate-400 bg-slate-200/60 dark:bg-slate-800 px-1.5 py-0.5 rounded`）
  - 合計ステップ数: `合計: {totalSteps} / 66`
- **各ステータスカラム** (`grid grid-cols-3 sm:grid-cols-6 gap-2 text-center`):
  - **ラベル**: `text-xs font-bold ${natureClass}`
  - **実数値**: `text-sm font-black ${natureClass || 'text-slate-800 dark:text-slate-100'}`
  - **入力欄**: `<input type="number" min="0" max="32" step="1" ... />`

### 2.3. 計算ロジック
- `src/utils/party.ts` から `getCalculatedStat` をインポート。
- 各ステータスについて:
  ```ts
  const calcStat = getCalculatedStat(
    s.key,
    currentPoke.base_stats[s.key],
    stepToEv(currentStep),
    member.nature
  );
  ```
