# 107_auth_logout_button_ui_and_functionality_plan.md

## 目的
ログイン時に「ログアウト」ボタンが表示されない（またはアイコンのみでテキストがなく視認性が著しく低い）問題を解消し、ユーザーが直感的にログアウトできるUIと機能を実装・整備する。

## 現状の課題と原因
1. **ログアウトボタンのテキスト欠落・視認性不足**:
   - `src/components/common/AuthButton.tsx` において、ユーザーログイン時（`user !== null`）にレンダリングされるログアウト用ボタンは、内部にテキスト（`{t('auth.logout')}`）を持たず、薄暗いグレーのアイコン（`i-lucide-log-out text-sm text-slate-500`）のみで構成されている。
   - ダークモードでは `text-slate-500` のコントラスト比が極めて低く、またタッチデバイスや各画面幅において「ボタン自体が存在しない」「どこを押せばログアウトできるか分からない」状態となっていた。
2. **TDDテストの不足**:
   - `src/components/common/AuthButton.test.tsx` において、未ログイン状態のテストのみが存在し、ログイン状態におけるユーザー情報表示やログアウトボタンの表示、ログアウト押下時の挙動に関するテストが欠落していた。
3. **アクセシビリティと統一感**:
   - 未ログイン時の「ログイン」ボタンはアイコン＋テキストの標準ボタンスタイル（`h-8 sm:h-9 px-3 py-1.5 text-xs whitespace-nowrap`）であるのに対し、ログイン時はテキストがなくスタイルが不揃いであった。

## 設計・改修方針

### 1. `AuthButton.tsx` のUI改修
- **テキストとアイコンの明示**:
  - ログアウトボタンに `icon="i-lucide-log-out"` およびラベル `{t('auth.logout')}` を含め、未ログイン時の「ログイン」ボタンと対称的な視認性の高いスタイルを適用する。
  - アイコン・テキストの色とコントラストを改善（`dark:text-slate-200`、ホバー時に赤系アクセント `hover:text-red-600 dark:hover:text-red-400`、`border-slate-300 dark:border-slate-700`）。
  - `aria-label={t('auth.logout')}` を明示し、スクリーンリーダーやアクセシビリティを担保。
- **レスポンシブ対応**:
  - デスクトップおよびタブレットでは「ログアウト」テキストを表示。スマートフォンなどの超極小画面でも破綻しないよう、適切なパディングとフォントサイズ（`text-xs`）を設定。

### 2. ログアウト処理の検証・連動
- `AuthContext.tsx` の `logout` 呼び出しが正常に完了し、即座に未ログイン状態（`user: null`）へ切り替わり、再度「ログイン」ボタンが表示されることを保証する。

### 3. TDD (テスト駆動開発) の徹底
- **Red フェーズ**:
  - `src/components/common/AuthButton.test.tsx` に以下のテストケースを追加：
    1. ログイン中のユーザー情報（名前・アバター/デフォルトアイコン）が表示されること。
    2. ログイン中に「ログアウト」ボタン（テキストおよびアイコン）が表示されること。
    3. ログアウトボタンをクリックした際に、ログアウトAPIが呼び出され、未ログイン表示（ログインボタン）に戻ること。
- **Green フェーズ**:
  - `AuthButton.tsx` を改修し、テストをすべてパスさせる。
- **Refactor フェーズ**:
  - スタイリングの整理、アクセシビリティ属性の確認、全テスト実行・Biome検証。

## 開発ロードマップ・工程
1. **計画書の作成・合意** (本ドキュメント)
2. **Red**: `AuthButton.test.tsx` にログイン時およびログアウト処理のテストケースを追加（失敗することを確認）
3. **Green**: `AuthButton.tsx` を改修し、ログアウトボタンのテキスト表示・コントラスト改善を行い、テストを成功させる
4. **Refactor & 全体検証**: 全体テスト（`npm test`）およびコード整形・静的解析（`npm run lint`）のパスを確認
