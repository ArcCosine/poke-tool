# 計画書: パーティ名入力UIの改善（パーティ名入力と保存済みパーティ選択の分離）

## 1. 概要
共有URL（`?p=...`）を経由してパーティ編成画面に移動した際、パーティ名の入力が正常に行えない問題（`Autocomplete` が候補選択前提となっており、自由入力が反映されずにリセットされてしまう問題、および「パーティ検索」と「パーティ名入力」の役割混同）を解消するため、UIコンポーネント（`PartySearch.tsx`）をリファクタリングし、直感的にパーティ名を入力・編集できるUIへ改善します。

---

## 2. 現状の課題と原因分析

### 2.1 原因1: `Autocomplete` コンポーネントの自由入力非対応
- 現在使用している `Autocomplete.tsx` は、テキストタイピング時に `onChange` をトリガーせず、候補一覧（`suggestions`）からの選択時かクリア時のみ `onChange` を発火する仕様となっています。
- 外側をクリックした際（`handleClickOutside`）も、`suggestions` に含まれない入力文字列は元の `value` にリセットされてしまうため、ユーザーがキーボードで新規パーティ名を入力しても反映されず消えてしまいます。

### 2.2 原因2: 「パーティ検索・切替」と「パーティ名入力」の責務混同
- 「既存パーティの検索・選択」と「現在編集中のパーティの名前の編集」を単一の入力ボックス（`Autocomplete`）で兼ねているため：
  - 共有URLから空のパーティ名で流入したユーザーにとって、どこにパーティ名を入力すべきか分かりづらい。
  - 既存パーティ一覧に存在しない新規の名前を入力することが本質的に困難。

---

## 3. UI改善方針

### 3.1 パーティ名入力フィールドの独立化（`Input` コンポーネントの採用）
- 編集中のパーティ名は、候補選択用コンポーネントではなく、標準の共通UIコンポーネント **`Input`（`src/components/common/Input.tsx`）** を使用して自由に入力できるようにします。
  - ラベル: **パーティ名**（`partySimulator.partyName`）
  - プレースホルダー: 「パーティ名を入力...」（`partySimulator.partyNamePlaceholder`）
  - 入力時（`onChange`）に親コンポーネントへ即座に入力内容が伝わり、自由に任意のパーティ名が入力可能。
  - 保存時バリデーションのフォーカス対象（`id="party-name-input"`）として確実に動作。

### 3.2 保存済みパーティ切り替えUIの整理
- 保存済みパーティの選択・切替は、独立したドロップダウン（`Select` コンポーネント または 切替ドロップダウン）として並列配置します。
  - ラベル: **保存済みパーティ**（`partySimulator.savedParties` / 保存数バッジ付き）
  - 保存済みパーティが複数ある場合、ここからワンクリックで目的のパーティを選択・切り替え。

### 3.3 レイアウト構成（`PartySearch.tsx`）
`card-premium` 内を以下のように2カラム（またはレスポンシブな行）で構成します：
```
+-----------------------------------------------------------------------+
| [👥 編集中のパーティ: (入力中のパーティ名 / 未設定)]      [全 N 個のパーティ中] |
|-----------------------------------------------------------------------|
|  [パーティ名 入力欄] (幅広・メイン)     |  [保存済みパーティ 切替] (幅固定)    |
|  <Input placeholder="パーティ名を入力..."> |  <Select options={parties}>          |
+-----------------------------------------------------------------------+
```
- PC環境（`md:` 以上）: 横並びで「パーティ名」を広く取り、右側に「保存済みパーティ切替」を配置。
- スマホ環境: 縦並びで押しやすく操作しやすいレイアウト。

## 4. 多言語対応（i18n）
以下の文言を4言語（`ja`, `en`, `ko`, `zh-Hant`, `zh-Hans`）に対称に追加します：
- `partySimulator.partyNamePlaceholder`:
  - `ja`: "パーティ名を入力..."
  - `en`: "Enter party name..."
  - `ko`: "파티 이름 입력..."
  - `zh-Hant`: "輸入隊伍名稱..."
  - `zh-Hans`: "输入队伍名称..."
- `partySimulator.selectSavedParty`:
  - `ja`: "保存済みパーティから選択"
  - `en`: "Select saved party"
  - `ko`: "저장된 파티에서 선택"
  - `zh-Hant`: "從已儲存隊伍中選擇"
  - `zh-Hans`: "从已保存队伍中选择"
