# 計画書 106: PC版ヘッダーのナビゲーションリンク削除

## 1. 概要と目的
現在、デスクトップ（PC）環境において、ヘッダー左側（ロゴの右隣）に各ページ（ダッシュボード、火力・耐久、努力値計算、パーティ編成、構築ランキング）への遷移リンクボタンが配置されています。
本ツールでは画面下部に全画面サイズ（モバイル・PC共通）で利用可能な固定ボトムナビゲーションが備わっており、ヘッダー側のナビゲーションリンクは冗長となっています。
ユーザーからの要望に基づき、PC版ヘッダーのナビゲーションリンク群を削除し、ヘッダーの表示領域をシンプルに整理します。

---

## 2. 変更対象ファイルと詳細仕様

### 2.1 対象ファイル
- [`src/components/common/Layout.tsx`](file:///home/arccosine/poke-tool/src/components/common/Layout.tsx)

### 2.2 変更内容
1. **デスクトップナビゲーション要素の削除**:
   - `<header>` 内の `<nav className="hidden md:flex items-center gap-1">...</nav>` ブロックを削除。
   - ロゴ（`AppIcon` + `Poke-Tool`）と右側のアクションコントロール（ログインボタン、言語セレクター、テーマ切替ボタン）のみのすっきりとしたヘッダー構成にします。
2. **ボトムナビゲーションの維持**:
   - 画面下部の `<nav aria-label="Bottom Navigation">` は引き続き `navItems` を用いてPC・モバイル双方で各ページへのナビゲーションを提供します。
3. **影響確認**:
   - `Layout.test.tsx` または関連テストが存在する場合、ヘッダーリンクの存在を前提としたテストがないか確認し、必要に応じてテストを更新します。
