# 計画書：特殊仕様の技（おはかまいり・ふんどのこぶし）の複数火力計算の実装

本計画は、イダイトウなどが使用する「おはかまいり」およびコノヨザルなどが使用する「ふんどのこぶし」について、ユーザーからの要望に基づく複数パターンの火力を計算してランキングに表示するためのものです。

## 1. 背景と目的
「おはかまいり」および「ふんどのこぶし」は、戦闘中の特定の条件（ひんし状態の味方の数、被弾回数）によって技の威力が変動する特殊な仕様を持っています。
これまでは基本威力（50）のみ、もしくは考慮されていなかったため、ユーザーが実際の対戦で想定される火力（味方が倒れた状態、攻撃を受けた状態、あるいは最大火力状態）をランキングや分析ツール上で比較・検討できるように、バリエーションを含めた計算ロジックを追加します。

## 2. 仕様定義

### 2.1. おはかまいり (Last Respects)
ゴーストタイプの物理技（ID: 854）。
味方のひんし回数に応じて威力が上昇します。
- 基本威力: 50
- 威力計算式: $50 + 50 \times (\text{ひんし状態の味方の数})$
- バリエーション定義:
  1. **おはかまいり (味方0落ち)**: 威力 50
  2. **おはかまいり (味方1落ち)**: 威力 100
  3. **おはかまいり (味方2落ち/最大火力)**: 威力 150 (味方2落ちを最大火力とする)

### 2.2. ふんどのこぶし (Rage Fist)
ゴーストタイプの物理技（ID: 889）。
自身が受けた攻撃の回数（被弾回数）に応じて威力が上昇します。ひんしになってもリセットされません。
- 基本威力: 50
- 威力計算式: $50 + 50 \times (\text{被弾回数})$
- バリエーション定義:
  1. **ふんどのこぶし (被弾0回)**: 威力 50
  2. **ふんどのこぶし (被弾1回)**: 威力 100
  3. **ふんどのこぶし (被弾2回)**: 威力 150
  4. **ふんどのこぶし (被弾3回/最大火力)**: 威力 200 (被弾3回を最大火力とする)

---

## 3. 実装アプローチ

### 3.1. `src/utils/calculator.ts` の修正
1. `calculateMaxDamage` 内で、対象ポケモンが習得可能な技を走査する際、技のIDが `854` (おはかまいり) または `889` (ふんどのこぶし) である場合、上記のバリエーションごとに仮想の技データを生成し、ループ処理に供給します。
2. 仮想の技データには、表示用の名前 (`displayName`) や、それぞれの条件に応じた `power` を設定します。
3. `bestMovesMap` は現在、技 ID をキー (`m.id`) としているため、同じ技 of 異なるバリエーションが上書きされて消えてしまいます。これを防ぐため、マップのキーを `string` に変更し、`${m.id}-${variationSuffix}` のようにユニークなキーを使用します。
4. `bestMovesMap` に格納する `moveName` には、`displayName` があればそれを優先して設定します。

### 3.2. テスト駆動開発 (TDD) の手順
1. `src/utils/calculator.test.ts` に「おはかまいり」と「ふんどのこぶし」の複数火力計算に対応したテストコードを追加する (Red)

## 4. 懸念点・確認事項
- 通常の「おはかまいり」や「ふんどのこぶし」はそのまま残すか、バリエーションに置き換えるか。
  - バリエーションである「おはかまいり (味方0落ち)」「ふんどのこぶし (被弾0回)」が通常の威力50に相当するため、単にすべてバリエーション表記に置き換える（元の50威力のプレーンな技はリストから除外し、バリエーションで網羅する）のが見やすく親切であると考えます。
