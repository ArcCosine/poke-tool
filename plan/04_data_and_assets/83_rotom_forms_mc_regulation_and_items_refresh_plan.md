# 計画83: ロトムのフォルム追加・レギュレーションM-C対応・使える道具刷新計画

## 1. 概要
ユーザーからの以下の要望に対応するための全体実装計画です：
1. **ロトムのフォルム追加**: ポケモン選択画面でヒートロトム、ウォッシュロトム、フロストロトム、スピンロトム、カットロトムを選択できるようにする。
2. **レギュレーションM-C対応**: GameWith（https://gamewith.jp/pokemon-champions/574460）に基づき、レギュレーションM-Cおよび新たに追加された35種類のポケモン（新メガシンカ・ZAメガシンカ・リージョンフォーム・フォルム違いを含む）を追加する。
3. **使える道具の刷新**: GameWith（https://gamewith.jp/pokemon-champions/546487）に基づき、ポケモンチャンピオンズで実際に使用可能な全持ち物（166種＋「なし」）へマスターデータを刷新する。

---

## 2. 詳細仕様と変更内容

### ③ 使える道具（持ち物）の刷新
現在 `items_master.json` には、対戦で持たせることができないモンスターボール類など350個の道具が含まれています。GameWithの持ち物一覧（546487）に掲載されている、ポケモンチャンピオンズで実際に使用可能な全166アイテム（および「なし」）のみに刷新します。

- **M-C追加アイテムを完全網羅**:
  - ながねぎ、ゴツゴツメット、ふうせん、レッドカード、しめつけバンド、だっしゅつボタン、ノーマルジュエル、グランドコート、エレキシード、サイコシード、ミストシード、グラスシード
  - 各種メガストーン（アブソルナイトZ、ガブリアスナイトZ、ルカリオナイトZ、ボーマンダナイト、グソクムシャナイト、セグレイブナイト等）
- **データ構造**:
  ```json
  {
    "id": number,
    "name": {
      "ja": "アイテム日本語名",
      "en": "Item English Name"
    }
  }
  ```
